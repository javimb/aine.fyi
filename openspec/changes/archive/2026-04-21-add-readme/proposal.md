## Why

The project has no README.md, making it harder for new contributors or developers to understand what the project does, set up their local environment, and run the application. A README is the standard entry point for any open-source or shared project.

## What Changes

- Add a `README.md` file to the project root with:
  - Project description and purpose
  - Local development setup instructions (prerequisites, install, run)
  - Available npm scripts (dev, build, lint, format, test)
  - Tech stack overview
  - Link to or summary of the AINEs dictionary and data sources
